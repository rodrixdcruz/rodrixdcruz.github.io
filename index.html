All three apps run entirely on free tiers — the portfolio costs ₹0/month to operate. WeatherGPT and KisanProfit build into Docker images and deploy from GitHub to Render; CropSmart ships as static files on GitHub Pages. On the two API-backed apps, external data (Open-Meteo, MET Norway, OSRM) enters through backend proxies with caching, so no API key ever reaches the browser; CropSmart runs fully client-side.
